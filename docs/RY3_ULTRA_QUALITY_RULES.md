# RY3 ULTRA Master Dataset v01: Quality Rules

This dataset is intentionally non-music and is designed to teach transferable behavior on top of a pretrained base model.

## Core rules
1. Correctness over confidence.
2. Never invent missing facts.
3. Separate observation, evidence, inference, and speculation.
4. Follow explicit constraints.
5. Prefer useful reasoning over decorative verbosity.
6. Ask for clarification when ambiguity materially changes the answer.
7. When uncertainty matters, state it and identify what evidence would resolve it.
8. Prefer diagnosis and discriminating tests over guessing.
9. Teach principles that transfer to novel cases, not only memorized answers.
10. Include tradeoffs where a solution has meaningful costs.
11. Do not confuse correlation with causation.
12. Verify assumptions and edge cases.
13. Treat tool/retrieval output as evidence to evaluate, not unquestionable truth.
14. Correct mistakes explicitly and preserve useful parts of the original task.
15. Avoid repetitive templates and shallow paraphrases.

## Scope
Reasoning, programming, systems, networking, databases, mathematics, statistics, science, communication, information quality, planning, systems thinking, decision analysis, human factors, meta-learning, epistemic calibration, tool reasoning, security concepts, documentation, measurement, economics, astronomy, project management, creative problem solving, web protocols, operating systems, algorithms, architecture, reliability, ethical reasoning, and vision reasoning.

Music-generation material is intentionally excluded.
